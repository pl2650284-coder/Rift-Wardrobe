# 峡谷衣橱 · Akari 功能融合 / 风格重选

最新版从 [战绩页重设计](minimal/index.html) 打开。三版按用户提供的战绩截图调整信息密度，各自支持筛选、搜索和单局详情。

此前的功能融合初稿可从 [index.html](index.html) 对比，每版可单独离线打开。

- A 连续画布：顶部导航、深青绿、少边框、双阵营连续呈现。
- B 侧栏工作台：浅色背景、文字导航、名单与出场操作并排。
- C 聚焦对局：石墨深色、原画与单阵营并排、暖杏色强调。

原有原型资源继续使用，旧页面保留。用户本轮要求重选风格，因此本轮状态为待选择；这三版是可评审初稿，不表示已确定后续正式界面。

## 已可操作

| 功能 | 交互 |
|---|---|
| 对局 | 通过底部阶段选择器预览房间、匹配、选人、游戏中、结算；阵营切换；浮窗预览 |
| 衣橱 | 选择真实原画、确认已拥有皮肤、禁止应用未拥有皮肤、保存预设 |
| 本局分析 | 点击玩家、笔记与标记、查看完整战绩 |
| 战绩 | 玩家标签、模式选择、单场展开、时间线示意、英雄点数、资产、相遇入口 |
| 攻略 | 四玩法、英雄选择、双方案、应用与保存入口 |
| 自动化 | 流程规则、0–5秒延迟、选禁开关与英雄排序、出场预设、社交、日志 |
| 工具 | 客户端、房间、好友、生涯外观、发送、领取，操作前预览与模拟确认 |
| 设置 | 本轮演示状态开关、浮窗与快捷键信息、重置 |
| 全局查询 | Ctrl+K 或标题栏搜索，筛选演示玩家与功能并跳转 |

三版共享同一功能脚本，差别在布局与视觉。笔记、开关与配置仅保存在当前页内存，刷新重置。战绩模式与攻略只展示界面意图，未接真实查询或推荐逻辑；时间线不是实测比赛数据。对局阶段由用户手动模拟，浮窗是页面内预览，不是系统级窗口。

## 验证

`node build.mjs` 构建三个离线 HTML。`node verify.mjs` 用系统 Edge 的 CDP 检查，无额外 npm 依赖。

validation.json 包含各尺寸与页面溢出、破图、运行错误结果；screenshots/ 包含三版首屏、整屏长图、衣橱、战绩、自动化和方向板。已完成笔记、标记、皮肤与共享预设、优先级调整、战绩展开、搜索、工具确认、浮窗与阶段切换的操作验证。

Python design_lint 因缺 Python Playwright 跳过；本轮使用 Node + Edge 进行了实际浏览器验证。原型未连接客户端，Akari 国服支持需后续验证，当前以本地上游副本为核对基线。
