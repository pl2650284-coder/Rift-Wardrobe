# 战绩页设计方向

三版完整交互初稿采用同一份战绩样本。另三版在 [六格预览](thumbs.html) 中展示。

| 方向 | 视觉来源与取舍 | 布局 |
|---|---|---|
| A 展开列表 | 用户提供的浅色 League Akari 战绩截图。借用桌面侧栏、段位摘要、按胜负区分的逐局列表。浅蓝和浅红用于快速定位胜负。 | 每行保留英雄头像、KDA、伤害、时间与真实装备图标，点开在原行下方显示两队阵容。 |
| B 左右分栏 | 从 Dieter Rams 对功能分组和操作可见性的思路出发。白底列表仅高亮当前选中对局。 | 左栏负责定位对局，右栏保持装备、数据和双方阵容同时可见。 |
| C 紧凑表格 | 项目本地上游副本的 `.cache/league-akari-reference/showcase-1.png`。借用深色工具外观和对齐的战绩列。 | 固定列用于比较多场 KDA、装备和伤害。单局详情占用独立的侧边面板。 |
| D 侧边档案 | 从 Massimo Vignelli 的网格约束出发，用固定宽度对齐段位和身份。 | 把账号与段位放在列表旁边，顶部留给筛选，主角仍是战绩。 |
| E 按日期分组 | 风格库 App 10 的原生精修样张。借用浅色底、小分组标题和行间细线。 | 按今天、昨天、更早切开战绩列表，适合找同一天连打的几局。 |
| F 赛果优先 | 风格库东亚 10 的服部一成样张。仅借用高对比标签的读法，省去错位和大色块。 | 胜负挪到每行左端成为窄栏，装备和数字跟随公共列线。 |

选择状态为待选。选定后在 `direction-approved.md` 记录用户选择和对应截图。
