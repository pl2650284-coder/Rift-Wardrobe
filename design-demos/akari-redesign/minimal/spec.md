# 峡谷衣橱战绩页原型

用户要求「我的核心追求只有一个，就是简洁明了」，并指出上一轮初稿过于简单，提供了 League Akari 的战绩页截图。以这张截图对照首屏的信息量、侧栏和战绩的行列关系。

主要任务是在 Windows 桌面上找玩家、读段位和扫最近战绩，再打开某一场看详情。首屏保留账号、单双排与灵活组排、筛选、赛果、英雄、KDA、出装、伤害和时间。双方阵容、参团率、补刀、金币随选中的对局查看。对局、皮肤、自动化、工具和设置沿用侧栏入口。

三份初稿使用同一组样本，参照尺寸为 1118 × 803，兼顾 1440 × 900 和 375 × 812。截图中的玩家数据仅作版式参考。原型使用虚构账号及战绩，搜索和自动化可在页面内演示。

品牌使用项目的峡谷衣橱标志，使用项目已有的 Data Dragon 英雄、装备、技能和符文图标。素材来源见 [品牌说明](../brand-spec.md)。三份原型均可离线单独打开。

运行 `node build.mjs` 生成原型和比较页，运行 `node verify.mjs` 用系统 Edge 验证并更新截图。验证尺寸和结果见 [validation.json](validation.json)。
