不做统计卡片矩阵；用列表 + 细分隔线；说明文字最多一行；演示免责只在原型控制台出现一次。

## 信息架构（按「玩家此刻要干什么」排）

| 一级 | 回答的问题 | 二级 | 来源 |
|---|---|---|---|
| 对局 | 现在这局怎么样、我要做什么 | 随游戏阶段切换：空闲/房间 → 匹配/确认 → 选人（衣橱｜本局｜符文出装）→ 游戏中 → 结算 | 衣橱(本项目) + 本局分析/小窗/选人台/秒退(Akari) |
| 战绩 | 我和别人打得怎么样 | 玩家标签页：我的 + 任意查询的玩家；总览/战绩/英雄点数/资产/相遇 | 个人信息(本项目) + 玩家标签页(Akari) |
| 攻略 | 这个英雄该怎么玩 | 四模式英雄榜 → 英雄详情（符文/技能/出装/海克斯符文/拍档/平衡调整） → 应用/存预设 | 官方榜单与海克斯(本项目) + OP.GG 英雄数据(Akari) |
| 自动化 | 哪些事交给助手 | 游戏流程｜选英雄｜出场预设｜社交｜操作日志 | 自动接受/自动换肤(本项目) + 自动化全集(Akari) |
| 工具 | 一次性动作 | 客户端｜房间｜社交｜生涯外观｜游戏内发送｜领取 | 工具集(Akari) + 皮肤原画(本项目) |
| 设置 | 助手本身怎么运行 | 通用｜窗口与浮窗｜对局分析｜快捷键｜隐私｜数据｜高级｜关于 | 双方设置并集 |

去重规则：同一状态只有一个编辑处（自动接受只在 自动化›游戏流程 编辑；标题栏、对局页、小窗只做快捷开关并跳转）；
「自动应用皮肤」并入 Akari 的「自动英雄配置」成为「出场预设」（符文 + 召唤师技能 + 皮肤）；
攻略的「应用到客户端 / 存为预设」写入同一份出场预设；玩家标记在本局、战绩、设置›数据三处共享。

## 场景与可读性

- Windows 桌面窗口，默认 980×700，检查 1440×900；观看距离约 50cm。
- 正文 ≥14px、标签 ≥12px，对比度 ≥4.5:1，可点区域 ≥40px。
- 字体：Segoe UI / Microsoft YaHei UI，本机字体，无外部请求。
