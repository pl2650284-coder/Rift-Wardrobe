# 峡谷衣橱 · 视觉探索

用户目标：整体视觉改版，重点是配色、布局、质感。用户参考偏好原话：「自由探索，先看三版效果」。

## 共同内容与约束

- Windows 桌面助手；以当前英雄薇恩的皮肤选择为代表屏幕。
- 统一主视口 980×700；补查 1440×900、760×560 和 375×812 的布局。
- 保留个人信息、游戏辅助、游戏资讯、应用设置四个已有入口。
- 主操作：浏览原画、选择皮肤、收藏、搜索和筛选；预览均不连接或写入真实客户端。
- 共享内容：经典、觅心猎手、灵魂莲华、源计划：净化、摄魂使者。
- 全部账号、拥有状态、选人状态均为演示；明显标记。摄魂使者演示为未拥有。
- 使用项目现有 app-mark.svg 及 Riot 官方原画；不增加产品功能或修改后端。
- 单 HTML 自包含；图片、标识内嵌，离线可查看。正文至少 14px，辅助文字至少 12px。

## Form 五问（代表屏幕）

叙事角色是选人时的皮肤操作屏幕；观看距离为桌面约 50cm；温度由方向分别定义；容量控制在一张主原画、五款皮肤与一组操作；视觉母题来自皮肤原画和「选好出场的样子」。
