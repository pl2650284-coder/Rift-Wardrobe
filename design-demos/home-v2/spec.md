## 项目与场景

- 峡谷衣橱：Windows 桌面英雄联盟助手，窗口 980×700（三版统一，额外查 1440×900、375×812）。
- 首页 = 「对局」：玩家在选人阶段打开，几秒内完成「看一眼局面 → 定皮肤 → 确认自动化状态」。
- 观看距离：桌面约 50cm；常与游戏客户端并排使用。

## 首页只说这些（assumption，按优先级）

1. 当前英雄与正在预览的皮肤：薇恩 · 灵魂莲华（主角原画）
2. 唯一主操作：使用这款皮肤（已在使用时为禁用态）
3. 薇恩的 5 款皮肤：经典、觅心猎手、灵魂莲华、源计划：净化、摄魂使者（未拥有）
4. 双方阵容：我方 5 / 对方 5，每人只显示 头像、英雄、位置、近期胜率
5. 自动化状态：自动接受（2 秒）、自动换肤，两个开关
6. 状态：选人中；数据为演示（全页只出现一次）

## 删掉 / 收进二级页

- 所有解释性句子（「先选好皮肤，再看看这局的阵容」「点击玩家查看近期摘要」「从这里进入玩家详情」等）
- 重复的演示免责声明（只留 1 处）
- 子导航「本局 / 皮肤衣橱 / 自动化」→ 合并为一页
- 一级导航收为 4 个：对局、玩家、攻略、设置（工具并入设置，资讯/榜单并入攻略）
- 卡片、分区标题、统计块矩阵

## 约束

- 品牌：沿用 app-mark.svg；Riot Data Dragon 官方原画与英雄头像（`design-demos/companion/assets.json`，已核实）
- 字体：Windows 本机 Microsoft YaHei UI / Segoe UI，衬线兜底 SimSun；无外部字体
- 正文 ≥14px，标签 ≥12px，对比度 ≥4.5:1，可点区域 ≥44px
