# 英雄联盟换肤助手 · 核心主屏重新设计 Spec

## 1. 项目定位
- **产品**：Windows 国服英雄联盟本地选人换肤桌面助手（原名「峡谷衣橱」，本次品牌名与视觉语言完全放开重设）
- **重做范围**：核心主屏（选人阶段皮肤衣橱 + 自动接受对局）
- **使用场景**：玩家在客户端进入选人阶段（Champ Select），30–90 秒内快速查看当前英雄已拥有皮肤原画、切换/收藏/随机皮肤，并在开局前随时开关与调节「自动接受对局（0–5 秒）」。

## 2. 受众与窗口规格
- **受众**：Windows 桌面端英雄联盟玩家（含多皮肤收藏玩家与快速排位玩家）
- **统一输出格式与尺寸**：单文件离线可交互 HTML 原型；桌面主视口 `1440×900`（内含桌面窗口边界或满幅桌面端布局），并兼容 `375×812` 窄屏响应式查看。

## 3. 核心信息与真实交互（三版共用，完全一致）
1. **顶部/全局状态**：
   - 客户端连接状态（演示预览 / 已连接 · 选人中）
   - 当前锁定英雄：`薇恩 · 暗夜猎手`（下路）
   - 一级模块切换占位：换肤衣橱（当前）、英雄榜、个人战绩、偏好设置
2. **主角：5 款真实皮肤原画预览与切换**（共用 `companion/assets.json` 官方原画）：
   - `经典`（已拥有，默认皮肤）
   - `觅心猎手`（已拥有，当前使用，已收藏）
   - `灵魂莲华`（已拥有，已收藏）
   - `源计划：净化`（已拥有）
   - `摄魂使者`（未拥有，只读预览，不可应用）
3. **皮肤操作与检索**：
   - 点击皮肤即切换原画预览（预览态 ≠ 已应用态）
   - 点击「确认使用」将预览皮肤应用为当前使用；未拥有时按钮不可点并明确提示「未拥有，仅支持预览」
   - 收藏切换（单款收藏状态实时更新）
   - 筛选：全部 / 可用 / 收藏
   - 实时搜索框（快捷键 `/` 聚焦）
   - 随机可用皮肤（快捷键 `R`）
4. **自动接受对局**：
   - 独立开关（开启/关闭）
   - 等待延迟调节：`0–5 秒`（整数档位，0 秒为立即接受）
   - 状态反馈与操作日志（可展开/查看 3 条演示日志：`14:32:08 换肤完成 薇恩·觅心猎手`、`14:31:54 检测到选人 召唤师峡谷·薇恩`、`14:28:41 自动接受对局 已确认进入房间`）

## 4. 质量与红线约束
- 正文 ≥ 14px，标签 ≥ 12px，正文对比度 ≥ 4.5:1
- 零模板装饰（无全大写装饰小标签、无中点拼接词组、无按钮尾巴 `→`、无假序号、无左彩条卡片）
- 所有图片通过 base64 内嵌，单文件离线打开零报错、交互全部真实可点
