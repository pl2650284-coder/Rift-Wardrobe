# 综合助手静态原型

用户请求：「能不能按照你的想法，帮我做一个静态原型出来看看效果」。

本原型是已选 A「沉浸衣橱」在同一项目中的功能扩展迭代，沿用 design-demos/direction-approved.md 的蓝金、原画、窄侧栏，不重新开启风格选择。按用户授权直接制作可评审结果。

范围：一个离线可打开的 HTML，五个主导航；对局有衣橱、本局、自动化；玩家详情、战绩展开、攻略预设、设置和工具反馈可点击。所有玩家、战绩、段位、概率、状态均为明确标注的演示数据；不连接客户端，不执行任何游戏操作。

布局假设：本局首屏为双阵营紧凑列表，详情按需侧滑；980×700 保持桌面体验，760×560 收紧，375 像素改为单列。沿用本机系统字体。

2026-10-22 用户修正：「我感觉主页分了很多小块，太乱了，重新设计一下，按照skill」。本轮沿用已批准的 A 方向，重新组织原型首页：一幅原画承载当前对局和唯一主动作；双方阵容置于同一连续列表，不做统计卡片矩阵。详细战绩、自动化设置、工具入口按需进入对应页面。这里是同项目已选方向的迭代，适用 skill 的方向门豁免。形式来自选人时先判断当前局面、再看队友和对手的顺序。

页面 form：衣橱负责情绪与原画舞台；本局负责快速比较和查看；玩家负责历史筛选；自动化负责规则和状态；攻略负责方案选择；工具负责明确可用动作。观看距离为桌面，正文14px以上；数据背景保持安静，金色仅强调选择与主按钮。形式来自选人过程中的英雄、阵营、位置与时间约束。

资产：复用项目 app-mark.svg 和 design-demos/assets 的官方原画。英雄方形头像由 Riot Data Dragon 16.21.1 下载并内嵌。无外部字体、脚本或运行时图片请求。这里是峡谷衣橱原型，不展示 LeagueAkari 标志或伪装其界面。
