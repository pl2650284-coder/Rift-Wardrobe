# 海克斯大乱斗官方英雄数据

入口：游戏资讯 → 海克斯大乱斗 → 英雄榜 → 点击英雄或“查看构筑”。

榜单首页按官网顺序显示峡谷、海克斯大乱斗、极地大乱斗、经典模式四个一级板块，默认选择峡谷。英雄榜、英雄资料和符文资料位于海克斯大乱斗板块内。目前已接入的官方统计是海克斯英雄榜与英雄详情；其余三个模式显示各自的待接入状态。

英雄详情包括英雄概览，以及符文、技能加点、出装、最佳拍档四个页签。符文支持品质筛选、名称搜索、强度或登场率排序、每页十条分页。技能优先级可以切换，逐级方案按排序展示前五项；出门装、鞋、优先成装、其余成装分别排序。最佳拍档使用英雄详情的搭档列表。

## 数据链路

Rust 的 `hextech.rs` 通过 reqwest 请求腾讯官网接口，解析后经 Tauri IPC 返回 TypeScript 页面。统计请求无需游戏账号或 LCU 凭据；LCU 仅用于优先读取本地图片。浏览器预览会提示使用桌面应用，不提供冒充官方的演示统计。

接口前缀：`https://mlol.qt.qq.com/go/battle_info/odp_proxy/`。

| 接口 | 参数 | 用途 |
| --- | --- | --- |
| fuwen_aram_hero_rank_v2 | dtstatdate=YYYYMMDD | 英雄总榜、英雄概览；与前一日比较登场率 |
| fuwen_hero_rank | championid=数字 | 该英雄的四类详情数据 |

元数据来自腾讯官网的 hero_list.js、hero/{id}.js、kiwi_augments.json 和 items.js。所有关联使用数字英雄／符文／装备 ID；名称不参与统计匹配。图片优先使用客户端资源，缺失时请求腾讯官方 PNG。图片域名、目录、大小和 PNG 文件头均经过校验。

## 解析约定

- 外层响应必须成功，先解码 data.result 内的 JSON 字符串，再解析嵌套字段。
- 符文优先读取 augment_json_irank 的完整列表，保留官方 S/A/B/C 强度。品质与强度独立；没有强度时显示“未提供”，不根据品质推断。
- 英雄概览的 T0–T4 评级复用官网按职业池排名、取最佳职业评级的规则。
- 符文、出门装、鞋、搭档中的比例为 0–1，转换成百分比；技能、优先成装、其余成装字段以基点存储，除以 100 得到百分比。
- 最佳拍档读取 championid_json，不使用全局最佳拍档榜代替。
- skill_json 的顺序原样保留，不自行生成加点方案。
- 详情以实际 dtstatdate 为准；概览请求同一统计日期。登场率变化仅在日期匹配时展示。
- 官网没有提供逐英雄、逐符文的胜率和样本数，页面仅展示官方强度与登场率。

统计在内存缓存十五分钟；英雄详情最多缓存二十四位英雄。静态资料缓存六小时。刷新按钮可绕过对应缓存；错误与缺失部分不会作为完整结果长期缓存。英雄切换或关闭详情后，旧请求不能覆盖当前界面。

## 验证

`npm test`、`npm run ui:build`、`cargo test --manifest-path src-tauri/Cargo.toml --lib`。

官方样本保存在 test/fixtures/hextech-official.json，统计日期为 2026-10-19，覆盖赫卡里姆 128 个符文（白银 37、黄金 44、棱彩 47）、技能方案、四类出装和五组搭档，以及两种百分比编码。

可显式运行联网检查：

`cargo test --manifest-path src-tauri/Cargo.toml hextech::tests::live_official_hextech_contract -- --ignored --nocapture`

当前实现不包含对局中的推荐、符文选择或弹窗。
