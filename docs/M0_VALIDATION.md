# M0 国服接口验证记录

更新时间：2026-09-22

这份记录区分“已经在真实客户端验证”和“代码已准备但仍需真实选人验证”。核心换肤闭环已通过，后续验证重点转为模式兼容、异常恢复和桌面端集成。

## 已验证

- [x] 从本机安装信息定位国服客户端目录。
- [x] 发现国服安装目录中的标准 `lockfile` 是空占位文件。
- [x] 从最新 `LeagueClientUx` 日志安全解析动态端口和临时凭证。
- [x] 凭证只保留在核心内存，不由 CLI、错误信息或诊断输出显示。
- [x] 通过本地 HTTPS 读取 `/lol-gameflow/v1/gameflow-phase`。
- [x] 皮肤轮播与皮肤选择器信息端点在当前版本可访问。
- [x] 读取到国服的 `showSkinSelector` 与 `skinSelectionDisabled` 门禁字段。
- [x] 当前客户端公开 `GET /lol-champ-select/v1/pickable-skin-ids`，用于写前资格复核。
- [x] 当前客户端公开 `GET/PATCH /lol-champ-select/v1/session/my-selection`，用于写入与权威读回。
- [x] 非选人阶段执行 `skins` 不返回伪造数据。
- [x] 非选人阶段即使显式执行 `apply ... --yes` 也不会发送皮肤写请求。
- [x] 自动化测试覆盖权威资格合并、实际 PATCH 载荷、资格拒绝、客户端禁用、换英雄上下文失效、单写互斥、写后验证和未知态不重试。
- [x] 已在国服真实英雄选择中确认普通皮肤可以切换，并由客户端读回确认结果。

## 待真实选人验证

- [ ] 进入和离开英雄选择时能正确识别状态变化。
- [ ] 选中、锁定和更换英雄时，`selectedChampionId` 与会话数据一致。
- [ ] `skin-carousel-skins` 的国服实际字段能正确区分可用、临时可用和不可用皮肤。
- [ ] 当前皮肤 ID 与英雄联盟客户端界面一致。
- [x] 对一个明确可用皮肤发送一次 PATCH 后，能读回相同的 `selectedSkinId`。
- [x] 连点不会产生并发写请求（自动化测试已覆盖）。
- [x] 换英雄、退出选人和客户端断开时，旧操作不会被报告为成功（自动化测试已覆盖；仍需桌面端实测）。
- [ ] 记录首批支持的真实模式；当前目标为召唤师峡谷，其他模式继续做能力探测后再宣称支持。

客户端发现、只读通信和一次真实换肤读回已经通过，国服专用凭证后备路径成立。RISK-02 已关闭；Tauri M1 桌面骨架已开始集成，模式覆盖和首编译验证仍待完成。
